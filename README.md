# Fedo

ویرایشگر Markdown دسکتاپ با ویرایش زنده، شبیه Typora، که از صفر ساخته شده است.

## قابلیت‌ها

- **تب‌ها:** هر فایلی که باز شود، حتی با دوبار کلیک از ویندوز، در یک تب همین پنجره باز می‌شود. می‌توانید تب‌ها را با کشیدن جابه‌جا کنید، با Ctrl+Tab بین‌شان بروید و با Ctrl+Shift+T تب بسته‌شده را برگردانید. برنامه موقع باز شدن، تب‌های قبلی را دوباره باز می‌کند.
- **تاریخچه‌ی نسخه‌ها:** با هر ذخیره و هر چند دقیقه یک بار هنگام نوشتن، یک نسخه ثبت می‌شود. تفاوت هر نسخه با متن فعلی یا نسخه‌ی قبلی قابل دیدن است و می‌شود نسخه را بازگرداند، نام‌گذاری کرد یا کپی کرد. تاریخچه بیرون از فایل شما نگه داشته می‌شود.
- **تم‌ها:** روشن، تیره، کاغذی، نورد و باغ. برای تم دلخواه، یک فایل CSS در «پوشه‌ی تم‌ها» بگذارید (از منوی تم).
- **فارسی کامل:** هر پاراگراف، تیتر، آیتم فهرست و جدول جهتش را از اولین حرفش می‌گیرد. کد همیشه چپ‌به‌راست است. فونت وزیرمتن داخل برنامه است و در حالت کد منبع هم حروف فارسی به هم چسبیده می‌مانند.
- **فونت:** دانا، ایران‌سنس X، ایران‌یکان X، وزیرمتن و نسخ داخل برنامه هستند و همه‌ی فونت‌های نصب‌شده روی ویندوز هم قابل انتخاب‌اند. برای متن، تیترها و منوها می‌شود فونت جدا گذاشت.
- **جدول:** با راست‌کلیک: افزودن و حذف سطر و ستون، جابه‌جایی سطر و ستون (Alt+جهت‌ها)، تراز ستون، کپی جدول به‌صورت Markdown. Ctrl+Enter سطر تازه می‌سازد.
- **فایل‌های اخیر:** ده فایل آخر در نوار کناری (بخش «اخیر») و در منو.
- **هنگام تایپ:** علامت‌های " ( [ { « خودکار بسته می‌شوند. Backspace بین جفت خالی هر دو را پاک می‌کند. با متن انتخاب‌شده: * پررنگ، _ کج، ~ خط‌خورده، ` کد. چسباندن آدرس روی متن انتخاب‌شده آن را لینک می‌کند. بعد از چسباندن متن پررنگ، ادامه‌ی تایپ معمولی است.
- **آدرس‌ها و مسیرهای انگلیسی** وسط متن فارسی به‌هم‌ریخته نمی‌شوند.
- **باز کردن سریع (Ctrl+P)، Ctrl+کلیک روی لینک، یادآوری جای نشانگر و اسکرول هر فایل، شمارش کلمات متن انتخاب‌شده، بازیابی پیش‌نویس‌های ذخیره‌نشده.**
- **زوم:** Ctrl+= و Ctrl+- و Ctrl+0 یا Ctrl+چرخ موس. اندازه‌ی متن، فاصله‌ی خطوط و عرض صفحه از دکمه‌ی «اندازه» در نوار پایین.
- **جستجو و جایگزینی (Ctrl+F و Ctrl+H):** فقط داخل متن و با تطبیق دقیق حروف (هٔ با ه یکی نیست). گزینه‌های حساس به حروف بزرگ و کوچک و کلمه‌ی کامل. جایگزینی تکی یا همه، با تأیید. اقدام‌های آماده: «هٔ» به «ه»، «ي/ك» عربی به فارسی (متن عربی دست نمی‌خورد)، اعداد انگلیسی و فارسی، فاصله‌های تکراری و پیدا کردن خط تیره‌ی بلند (em dash).
- **حالت امن (F8):** فایل فقط خواندنی می‌شود و برنامه آن را برای همان فایل به خاطر می‌سپارد.
- **آیکن برنامه:** دوازده آیکن، از منو «آیکن برنامه…».
- **امکانات دیگر:** کد منبع (Ctrl+/)، درخت فایل‌های پوشه، سرفصل‌ها، جدول، فرمول ریاضی، نمودار mermaid، چسباندن تصویر (در پوشه‌ی assets کنار فایل ذخیره می‌شود)، جستجو و جایگزینی، خروجی HTML و PDF، شمارش کلمات، ذخیره‌ی خودکار و تشخیص تغییر فایل از بیرون برنامه.

## ساخت از روی کد

```
npm install
npm start          # اجرای برنامه
npm run dist:win   # ساخت نصب‌کننده‌ی ویندوز در پوشه‌ی release
```

## ساختار کد

- `electron/main.js`: پنجره، تک‌نمونه بودن برنامه (فایل جدید در تب)، فایل‌ها، تاریخچه، خروجی PDF
- `renderer/src/app.js`: تب‌ها، نوار کناری، تنظیمات، میان‌برها
- `renderer/src/editor.js`: ادیتور (Milkdown) و تشخیص جهت هر پاراگراف
- `renderer/src/history.js`: پنل تاریخچه
- `renderer/src/themes.css`: تم‌ها
